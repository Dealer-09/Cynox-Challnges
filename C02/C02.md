## Description
S.H.I.E.L.D.'s comms were compromised. A HYDRA agent transmitted a message through three layers of obfuscation before going dark. Analysts already cracked the first layer — it's Base64. But whatever they decoded still looks like noise. The Director says there's more to it. Can you peel back every layer and expose the message?

## Files
- `intercepted_signal.txt`

## Hint
*"Cut off one head, two more shall take its place."* — Don't stop at the first decode.

## Solution
Three-layer decode chain:

1. **Base64 decode** the contents of `intercepted_signal.txt`
2. **Reverse** the resulting string
3. **Hex decode** the reversed string to get the flag

```python
import base64

data = open("intercepted_signal.txt").read().strip()
step1 = base64.b64decode(data).decode()
step2 = step1[::-1]
flag = bytes.fromhex(step2).decode()
print(flag)
```
