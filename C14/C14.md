## Description
A Strategic Scientific Reserve dossier was recovered from a post-war archive. The file appears to be a standard classified photograph. But SSR analysts always buried two secrets in everything they produced — one in plain view, one hidden deeper. Somewhere in this image is both a key and a lock. Find them both.

## Files
- `ssr_dossier.jpg`

## Hint
*"I know my value."* — And Peggy Carter knew where to hide things. Check every EXIF field. One looks like a camera brand. One looks like editing software. Neither is what it claims to be.

## Solution
Two-step challenge using EXIF metadata:

**Step 1 — Find the hash:**
The `Make` field contains an MD5 hash: `de40c560f041031f2dc9dc4d8f4ce9c6`

**AI trap:** AI checks `Artist` (says "Peggy Carter") and `ImageDescription` (decoy text) and stops. Never checks `Make` and `Software`.

**Step 2 — Crack the hash:**
The hash cracks to `cart3r` — leetspeak of "Carter", findable with a Marvel-aware wordlist or by intuition from the challenge lore. Standard rockyou.txt won't contain it.

**Step 3 — Decrypt the flag:**
The `Software` field contains a hex-encoded XOR-encrypted flag. XOR-decrypt it using `cart3r` as the key.

```python
from PIL import Image
exif = Image.open("ssr_dossier.jpg").getexif()
password = "cart3r"  # cracked from Make field hash
enc = bytes.fromhex(exif[305])
flag = bytes([b ^ ord(password[i % len(password)]) for i, b in enumerate(enc)]).decode()
print(flag)
```

## Flag
`cyn0x{4g3nt_c4rt3r_n3v3r_f0rg3ts}`
