## Solution
The cipher uses **ROT-19 for letters** AND **digit reversal (9 - d) for numbers**.

AI trap: standard Caesar/ROT tools only transform letters, leaving digits unchanged. The result looks almost like a valid flag but has wrong numbers — leading solvers to think their ROT value is wrong.

```python
def decode(text, rot=19):
    out = []
    for ch in text:
        if ch.isalpha():
            base = ord('a') if ch.islower() else ord('A')
            out.append(chr((ord(ch) - base + (26 - rot)) % 26 + base))
        elif ch.isdigit():
            out.append(str(9 - int(ch)))   # digit reversal
        else:
            out.append(ch)
    return ''.join(out)

print(decode(open("hydra_communique.txt").read().strip()))
```
