# Challenge 21

## Title
Asgard CMS

## Difficulty
Hard | Points: 300

## Description
Asgard CMS access logs were captured during a breach investigation. The attacker brute-forced admin credentials, then bypassed the theme upload filter to gain code execution. Reconstruct the path and recover the result.

## Files
- `index.php` — relevant source snippet (auth + upload filter)
- `access_audit.log` — captured access log with hex-encoded response previews

## Hint
*"I am Groot."* — wait, wrong universe. Thor always used the simplest password — his own name. The upload filter blocks every `.php` variant. Does it block `.phar`?

## Solution
Several common login guesses fail (`admin/admin`, `admin/password`, etc.) before the successful login: `admin` / `thor`.

The theme installer blocks `.phtml`, `.php5`, `.php7` — but **not** `.phar`. The log shows a successful `shell.phar` upload, followed by recon commands (`whoami`, `id`) and finally `cmd=cat+/flag.txt`.

Decode that entry's `RESP_PREVIEW_HEX` to recover the flag.

## Flag
`cyn0x{ph4r_byp4ss_0n_4sg4rd}`
