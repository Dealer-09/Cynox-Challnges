# Challenge 12

## Title
Fury's Back Door

## Difficulty
Medium | Points: 200

## Description
A S.H.I.E.L.D. agent portal was compromised. Network monitoring captured the full attack chain — from initial reconnaissance to command execution. Reconstruct the path the attacker took and recover what they extracted.

## Files
- `index.php` — the vulnerable diagnostic panel (source code)
- `access_audit.log` — captured access log with hex-encoded response previews

## Hint
*"I'm the spy. I'm always right behind you."* — Recon starts where spiders check first. Once inside, the filter blocks spaces, `cat `, `ls `, and the word `flag`. What shell tricks avoid all four simultaneously?

## Solution
The log shows the attacker fetching `/robots.txt`, which discloses `/S.H.I.E.L.D_internal/`. Several blocked command attempts follow (`cat /flag.txt`, `cat${IFS}/flag.txt` — both contain the word "flag" and/or a literal space, triggering the filter).

The successful request uses `$IFS` as a space substitute, `tac` instead of `cat`, and a glob `/f*` to avoid the literal word "flag":
```
tac${IFS}/f*
```

Decode that entry's `RESP_PREVIEW_HEX` to recover the flag.
