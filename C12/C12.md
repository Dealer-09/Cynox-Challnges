# Challenge 12

## Title
Fury's Back Door

## Difficulty
Medium

## Points
200

## Description
A S.H.I.E.L.D. agent portal is live on the network. The landing page just shows a warning notice — nothing useful. But Fury always leaves a back door for emergencies. Find it, get in, and read the flag at `/flag.txt`.

## Service
Live web challenge — provided URL on competition day.

## Hint
*"I'm the spy. I'm always right behind you."* — Start where all good recon starts. What do spiders check first?

## Solution

**Step 1 — Enumeration:** Check `/robots.txt`. It reveals `/S.H.I.E.L.D_internal/`.

**Step 2 — Hidden panel:** Visit the path to find a diagnostic command panel.

**Step 3 — Filter bypass:** The filter blocks:
- The word `cat` followed by space
- The word `flag`  
- Literal space characters

Bypass using `$IFS` (shell internal field separator = space) and `tac` instead of `cat`, and a glob `/f*` to avoid the word "flag":

```
tac${IFS}/f*
```

**AI trap:** AI suggests `cat /flag.txt` → blocked (space + "flag"). Then tries `cat${IFS}/flag.txt` → blocked ("flag" in path). Never thinks to use glob `/f*` to avoid the keyword.
