## Files
- `surveillance_log.png`

## Hint
*"I've got red in my ledger."* — Maybe it's in the red channel. But which end do you start reading from?

## Solution
The flag is hidden using **LSB steganography on the red channel**, but with **MSB-first bit order** — the opposite of what every standard tool (StegOnline, zsteg, stegsolve) assumes.

```python
from PIL import Image

img  = Image.open("surveillance_log.png")
pix  = list(img.getdata())
bits = [(p[0] & 1) for p in pix]   # red channel LSBs

out = []
for i in range(0, len(bits) - 7, 8):
    byte = 0
    for j in range(8):
        byte = (byte << 1) | bits[i + j]  # MSB-first reconstruction
    if byte == 0:
        break
    out.append(chr(byte))

print(''.join(out))
```
