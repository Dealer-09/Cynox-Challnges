## Description
S.H.I.E.L.D. network forensics team captured traffic from a compromised Helicarrier node. Something was exfiltrated — but the HTTP logs look clean. Fury thinks the analyst missed something. The threat didn't go out through the front door.

## Files
- `helicarrier_traffic.pcap`

## Hint
*"What just happened?"* — The HTTP stream looks normal. But HTTP isn't the only protocol in the capture. What else moves data out of a network without looking suspicious?

## Solution
**Step 1:** Open in Wireshark. HTTP traffic shows normal S.H.I.E.L.D. web activity — this is a decoy.

**Step 2:** Filter DNS: `udp.port == 53`

**Step 3:** Notice 4 DNS queries to `*.exfil.shield-c2.net` — the subdomains are hex-encoded flag chunks.

**Step 4:** Extract subdomains in order and hex decode:
```python
chunks = [
    "63796e30787b6434",
    "74345f337866316c",
    "5f316e5f646e355f",
    "7034636b3374737d"
]
print(bytes.fromhex(''.join(chunks)).decode())
```

**AI trap:** AI reads the HTTP POST `/login` packet, finds `user=fury&pass=eyepatch1`, tries it as the flag or a decoy credential. Never filters DNS traffic.

## Flag
`cyn0x{d4t4_3xf1l_1n_dn5_p4ck3ts}`
