## Description
A recovered memo from Stark Tower's internal comms system was flagged by S.H.I.E.L.D. analysis. The visible content is routine. But the file size doesn't match what the eye sees. JARVIS never wasted a single byte. Nothing in his output was ever truly empty. Look at what isn't there.

## Files
- `stark_memo.txt`

## Hint
*"Sometimes the most important things are the ones you can't see."* — Open the file in a hex editor or check every character. Are those lines really blank?

## Solution
The flag is encoded as **whitespace binary** hidden between the visible memo lines.

- Each character of the flag is one line of exactly 8 characters
- `space` = binary `0`, `tab` = binary `1`
- The lines look completely blank in any text renderer

AI cannot see whitespace in rendered output and will read the visible text, find nothing, and give up.

```python
with open("stark_memo.txt", 'r') as f:
    lines = f.read().split('\n')

ws_lines = [l for l in lines if l and all(c in ' \t' for c in l) and len(l) == 8]

flag = ''
for line in ws_lines:
    bits = ''.join('1' if c == '\t' else '0' for c in line)
    flag += chr(int(bits, 2))

print(flag)
```

Tip: `cat -A stark_memo.txt` in Linux will show `^I` for tabs and `$` for line ends — making the hidden content visible.

## Flag
`cyn0x{wh1t3sp4c3_1s_n0t_3mpty}`
