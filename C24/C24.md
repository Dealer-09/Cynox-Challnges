# Challenge 24

## Title
Ultron's Core

## Difficulty
Hard

## Points
300

## Description
Stark's team recovered a compiled binary from an abandoned HYDRA server. It appears to be an access verification tool — but the source code was never found. Somewhere inside is the flag, locked behind Fernet encryption. The key isn't stored directly. Ultron was smart enough not to do that.

## Files
- `ultron_core.pyc` (PyInstaller-extracted .pyc artifact)

## Hint
*"I had a vision. The key to the future."* — The key isn't what you find. It's what you do with what you find. Finding the seed is step one. Deriving the key is step two.

## Solution
**Step 1 — Decompile the .pyc:**
```bash
uncompyle6 ultron_core.pyc  # or decompile3
```

**Step 2 — Recovered source reveals:**
- `_x = [116,104,52,110,111,115,95,115,110,52,112]` → `b"th4nos_sn4p"`
- Key derived as: `base64.urlsafe_b64encode(hashlib.sha256(seed).digest())`
- Fernet-encrypted blob stored in `blob`

**AI trap:** AI extracts `_x`, converts to bytes, tries it directly as Fernet key → `binascii.Error: Invalid base64-encoded string`. Then tries various encodings of the raw bytes. Never applies the SHA256 → base64url derivation chain.

```python
import base64, hashlib
from cryptography.fernet import Fernet
seed = bytes([116,104,52,110,111,115,95,115,110,52,112])
key  = base64.urlsafe_b64encode(hashlib.sha256(seed).digest())
f    = Fernet(key)
blob = b'gAAAAABp_0S4SnTiVckOvzol_5KWJ5axp4pZwFu_rgEb3d2X7-cVGhPMtSQKbiZQxsdZEL9oTWAAAU5cdXRT9fhn6ZZIAdqNE4Xvq_5GEzZzMV_6YbuHiHccOWkNS2yMOyfg_y_8sYyp'
print(f.decrypt(blob).decode())
```
