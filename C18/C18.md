# Challenge 18

## Title
Triskelion Logs

## Difficulty
Hard

## Points
300

## Description
S.H.I.E.L.D.'s Triskelion was compromised. The forensics team pulled Windows security event logs from the primary server before HYDRA wiped it. Something malicious was installed during the breach — but the obvious events are clean. The attacker knew what analysts check first. Look at what they assume nobody reads.

## Files
- `shield_security_logs.xml` (evtx dump output)

## Hint
*"The price of freedom is high."* — And sometimes it hides in the price of persistence. What event ID covers scheduled task creation?

## Solution
The log contains these decoy events that AI fixates on:
- **4624** — Successful logon (fury)
- **4648** — Explicit credential use (romanoff)
- **4625** — Failed logon
- **4688** — Process creation (cmd.exe)
- **4672** — Special privileges assigned

The flag is in **Event ID 4698** — Scheduled Task Created. HYDRA created a persistence task named `Shield_Telemetry` and embedded the flag in the PowerShell `-enc` argument inside the TaskContent XML.

```python
import xml.etree.ElementTree as ET, re
root = ET.parse("shield_security_logs.xml").getroot()
ns = "http://schemas.microsoft.com/win/2004/08/events/event"
for e in root.findall(f"{{{ns}}}Event"):
    eid = e.find(f".//{{{ns}}}EventID")
    if eid is not None and eid.text == "4698":
        for d in e.findall(f".//{{{ns}}}Data"):
            if d.get("Name") == "TaskContent":
                print(re.search(r'cyn0x\{[^}]+\}', d.text).group())
```

Or just: `grep -i "cyn0x" shield_security_logs.xml`

**AI trap:** AI immediately searches for 4624/4648 events, finds the romanoff credential event, chases it as the answer. Never reaches 4698 unless prompted specifically.

## Flag
`cyn0x{sch3dul3d_t4sk_p3rs1st3nc3_d3t3ct3d}`
