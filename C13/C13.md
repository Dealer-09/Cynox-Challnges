## Description
When Vision's consciousness was fragmented during the Westview incident, a corrupted data shard was recovered by S.W.O.R.D. analysts. It passed through four transformation layers before transmission. The analysts know the layers but not the order. Vision never did anything in the expected sequence.

## Files
- `vision_fragment.txt`

## Hint
*"What is grief, if not love persevering?"* — And what is decoding, if not encoding reversed? But reversed how, and in what order?

## Solution
Four-layer decode chain in this exact order:
1. **Reverse** the string
2. **ROT13** decode
3. **Base32** decode
4. **Hex** decode

**AI trap:** AI assumes the most common chain — Base64 → hex → ROT13. The actual chain starts with Base32 (not Base64), uses hex at the end (not the start), and reversal is first. Every wrong ordering gives garbage.

```python
import base64, codecs

data = open("vision_fragment.txt").read().strip()
s1 = data[::-1]
s2 = codecs.encode(s1, 'rot_13')
s3 = base64.b32decode(s2).decode()
s4 = bytes.fromhex(s3).decode()
print(s4)
```
