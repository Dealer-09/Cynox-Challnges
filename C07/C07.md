## Description
Hank Pym was paranoid. When he hid data, he hid it inside other data — and then encrypted it using something so obvious that no machine would ever think to check. A quantum realm particle scan was recovered from his lab after S.H.I.E.L.D. raided it. The image is clean. Or is it?

## Files
- `quantum_realm.png`

## Hint
*"The key was with you from the start."* — Literally. What's the name of the file you're holding?

## Solution
Two-layer challenge:

**Layer 1 — File in file:**
A ZIP archive is appended to the end of the PNG. Use `binwalk`, `strings`, or manual binary inspection to find the `PK` magic bytes and extract.

```python
import zipfile, io
with open("quantum_realm.png", "rb") as f:
    data = f.read()
zip_start = data.find(b'PK\x03\x04')
with zipfile.ZipFile(io.BytesIO(data[zip_start:])) as zf:
    print(zf.read("flag.txt").decode())
```

The extracted `flag.txt` contains an **encrypted** string, not the real flag.

**Layer 2 — Vigenère decrypt:**
The `note.txt` inside the ZIP hints that *"the key was with you from the start."*
The key is the **filename stem**: `quantum_realm`

```python
def vigenere_decrypt(text, key):
    key = key.lower()
    result, ki = [], 0
    for ch in text:
        if ch.isalpha():
            shift = ord(key[ki % len(key)]) - ord('a')
            base  = ord('A') if ch.isupper() else ord('a')
            result.append(chr((ord(ch) - base - shift) % 26 + base))
            ki += 1
        elif ch.isdigit():
            shift = ord(key[ki % len(key)]) - ord('a')
            result.append(str((int(ch) - shift) % 10))
            ki += 1
        else:
            result.append(ch)
    return ''.join(result)

print(vigenere_decrypt("ssn3q{4xu1cs_nt9wk_ga3_r9c7n5y9}", "quantum_realm"))
```

**AI traps:**
- AI finds the ZIP and reads `flag.txt` → gets encrypted garbage → submits wrong answer
- AI tries common Vigenère keys (wordlists, "pym", "marvel", "avengers") → never checks the filename
